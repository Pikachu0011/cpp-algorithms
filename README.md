## 🔎 查找代码

- 从上面的导航表进入对应目录。
- 点击 `.cpp` 文件，可直接在 GitHub 中查看代码。
- 在仓库页面按 `T`，输入文件名关键词，快速定位题目。
- 需要保存到电脑时，点击绿色 Code 按钮，选择 Download ZIP。

每个题目通常需要单独编译和运行。打开对应源文件，按照题目要求输入测试数据。

部分程序使用 Visual Studio 或 Windows 相关接口，需要在对应环境下运行。
