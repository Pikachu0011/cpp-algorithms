# C++ 算法练习与竞赛题解

这里收录了我学习 C++、刷 PTA 和准备竞赛时写下的代码，共 764 个 `.cpp` 源文件。我保留了当时的项目目录，方便回头找一道做过的题，或复习某个算法的写法。

**[下载完整代码包](./cpp-algorithms.zip)**

## 目录导览

| 想找什么 | 解压后可以先看这些目录 |
| --- | --- |
| PTA 与天梯赛练习 | `pta`、`pta题`、`pta天梯赛` |
| 算法专题与模板 | `并查集`、`广度优先搜索`、`代码模板` |
| C++ 基础与标准库 | `初识C++`、`c++_stl`、`stringstream` |
| 竞赛与假期练习 | `2025.3.9比赛`、`winter_vacation` |
| 课程编程题 | `操作系统编程题` |

## 如何使用

下载并解压 `cpp-algorithms.zip`，进入感兴趣的目录，用 Visual Studio 或其他 C++ 编辑器打开 `.cpp` 文件。查找某道题时，也可以直接在解压后的文件夹中搜索题名关键词。
